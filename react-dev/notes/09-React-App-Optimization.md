3. Is it mandatory to follow the convention that hook names should always start with the word "use"?
No, However, it is recommended and considered best practice according to React documentation. Additionally, in the industry, many senior developers use linters, which can be configured to enforce this rule. If the linter is set up to require that hooks always start with "use," then it becomes mandatory, and an error will be thrown if the convention is not followed.
